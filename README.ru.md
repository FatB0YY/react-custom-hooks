# React Custom Hooks

Подборка кастомных React-хуков, покрывающая паттерны, которые постоянно всплывают в реальных приложениях: сохранение стабильности колбэков между рендерами, безопасная подписка на события, ограничение частоты вызовов, объединение ref'ов и наблюдение за DOM.

Каждый хук лежит в своей папке: `doc.md` с разбором логики и обоснованием решений, `example.tsx` с примером использования.

## Почему в основе большинства хуков — `useRef`

Большинство хуков здесь построены на `useRef`, а не на состоянии. Разница принципиальная: обновление состояния планирует новый рендер, а ref хранит изменяемое значение между рендерами, не вызывая их.

Поэтому ref — правильный инструмент везде, где значение должно оставаться актуальным, но само по себе его изменение не должно приводить к перерисовке компонента: последняя версия колбэка, предыдущее значение для сравнения, подписка, которую нужно снять. Использование состояния в таких случаях даёт либо лишние рендеры, либо устаревшие замыкания.

## Хуки

### Эффекты и жизненный цикл

| Хук | Что делает |
| --- | --- |
| `useUpdateEffect` | Выполняет эффект при изменении зависимостей, пропуская первый рендер |
| `useIsMounted` | Сообщает, смонтирован ли компонент в данный момент |

### Стабильные значения и ссылки

| Хук | Что делает |
| --- | --- |
| `useLatest` | Хранит актуальное значение переменной, не добавляя её в зависимости эффекта и не вызывая рендер |
| `usePrevious` | Возвращает значение пропса или состояния с предыдущего рендера |
| `useEvent` | Возвращает колбэк со стабильной идентичностью, всегда вызывающий последнюю версию переданной функции |
| `useCombinedRef` (`useForkRef`) | Объединяет несколько ref'ов в один callback ref |

### События

| Хук | Что делает |
| --- | --- |
| `useWindowEvent` | Подписывается на событие `window` с автоматической отпиской |
| `useEventListener` | Вешает обработчик на DOM-элемент из ref, управляется флагом `active` |
| `useEventListenerCbRef` | Вешает обработчик через callback-ref, назначая его напрямую в атрибут `ref` элемента |
| `useOutsideClick` | Отслеживает клики за пределами заданного элемента |

### Ограничение частоты вызовов

| Хук | Что делает |
| --- | --- |
| `useDebounce` | Откладывает вызов до момента, когда поток вызовов прекратится на заданный промежуток |
| `useRafThrottle` | Ограничивает колбэк одним выполнением на кадр анимации, синхронизируя работу с циклом отрисовки браузера |

### Наблюдение за DOM

| Хук | Что делает |
| --- | --- |
| `useResizeObserver` | Отслеживает изменение размеров DOM-элемента через `ResizeObserver` с использованием callback-ref |

### Отладка

| Хук | Что делает |
| --- | --- |
| `useWhyDidUpdate` | Выводит в консоль, какие пропсы изменились между рендерами — для поиска причин лишних перерисовок |

## Использование

У хуков нет зависимостей, кроме React. Скопируйте нужную папку в свой проект или прочитайте `doc.md` и адаптируйте реализацию под себя.
